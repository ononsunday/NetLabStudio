# 操作指南

## 窗口与数据查看

左侧切换工作区，顶部切换主题、全局知识搜索和设置。导航栏与右侧知识面板可收起，为画布留出空间。`Ctrl+K` 聚焦搜索，`Ctrl+S` 保存当前实验，`F5` 刷新当前本机观察或实验记录。

表格点击列头排序；右键可以筛选当前表格。结构视图展示字段和证据，JSON 标签保留完整结果。复杂数据树最多展开前 1000 个数组元素，原始 JSON 不受该显示限制。

## 拓扑与电路

拓扑通过“添加设备”创建节点。Ctrl 点击选择两台设备，再连接明确端口；已连接端口不能重复接线。双击设备编辑接口、网关、DHCP/NAT 与路由配置。示例中的 `203.0.113.0/24`、`2001:db8::/32` 只用于教学，未表示本机地址。

滚轮缩放，“平移 / 框选”切换操作模式。“适应画布”恢复整体视图。右键可以关闭或恢复设备；编辑链路的 `up` 可以改变运行中的链路状态。改变其他配置会开始新的模拟状态。

虚拟帧移动由事件驱动。双击帧标记检查当前封装。暂停后可单步，重置会清除当前模拟状态。快照保存等待队列和随机状态，恢复后保持暂停，可继续逐步运行。

电路画布支持拖动门、Ctrl 选择两个门并连接。输入值在 JSON 输入框中设置，门输出由逻辑核心求值；环路和门输入数量错误会显示具体错误。完整电路配置可编辑，拖动位置保存在配置中。

CPU 源码或模板修改后，先点击“汇编 / 重置”，再单步或运行。`SEND` 和 `RECV` 都属于模拟；独立 CPU 的 `RECV` 使用教学回环队列。“CPU 消息交给虚拟网络”会重新执行当前汇编，并使用仅接收实际虚拟回显的外部接收队列。

## 真实网络请求

诊断需要单个 IP/主机名，HTTP/HTTP3 需要完整 URL。仅向你有权测试的目标执行请求。本地测试优先使用 `127.0.0.1`。请求失败会显示错误及已取得的证据；Ping 不响应不能独自证明某个网页服务不可用。

Web 页面可以执行实际 DNS、DoH、DoT、HTTP、TLS 和 HTTP/3。DNS 记录选择与 HTTP 方法分别控制对应操作。POST 正文和 Header 只在你点击执行后发送。本地 HTTP/HTTPS 启动后自动填入目标，HTTPS 实验使用该服务器的临时测试 CA。

“访问网站”真实探测中的各阶段是独立连接，不能当作浏览器一次会话的抓包。教学时序另行标注，并按 DNS、连接、TLS、HTTP 和传输结果的计算顺序排列。

## 抓包

导入自己有权分析的 PCAP/PCAPNG，选择协议筛选，点击行查看字段和原始字节。TCP 时序由文件中的序列号、确认号和标志构建；重复包可能来自重传，也可能来自抓包位置，工具不会把这一推断当作确定结论。

实时抓包前先检查支持状态，再填写明确接口。持续时间和包数量有限。当前电脑没有 Npcap，因此实时抓包不可用；文件解析和教学包查看仍正常工作。软件不会尝试解密没有密钥的 HTTPS。

## 课程与挑战

课程条目包含概念、过程、例子、字段、练习、相关内容和资料入口。自由模式可以先做实验，教学引导模式建议按步骤记录观察；挑战模式先显示问题，再通过关联实验验证。

综合实验 D 使用随机种子选择有明确原因的虚拟故障。挑战模式隐藏直接答案，保留可诊断的配置和证据。提交故障判断后，可以在拓扑中修复并重测。对错记录与知识题分别保存在本机。
